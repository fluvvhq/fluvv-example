# Fluvv example: car sales

A complete [Fluvv](https://fluvv.se) repository: car sales across five
dealerships, from landing CSVs to business-ready gold tables, in ten
contracts. Clone it to see what a Fluvv project looks like, or to try Fluvv
on something real.

```text
contracts/
  bronze/sales/          cars, employees, locations, landed as delivered
  silver/sales/          deduplicated, typed, validated
  gold/sales/            cars, employees, locations, dealership_performance
  spark_schemas/         generated by `fluvv export`
  ingestion_config/      generated by `fluvv export`
governance/
  domains/sales.yaml             owner and experts
  glossaries/sales.yaml          every business term the columns use
  products/sales_reporting.odps.yaml   the data product and its tables
data/landing/sales/      the source CSVs (synthetic)
openmetadata/            OpenMetadata 2.0.1, to publish to
```

## Lint and compile (open source)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

fluvv lint        # each contract and governance file on its own
fluvv compile     # references between files, then target/manifest.json
```

`target/manifest.json` holds every contract, the governance around it, and
table- and column-level lineage derived from the transform SQL.

## Build, test and publish (Fluvv Engine)

Fluvv Engine needs a license; [fluvv.se/engine](https://fluvv.se/engine)
says how to get one. With your license key and license file:

```bash
export FLUVV_LICENSE_KEY="<your license key>"
pip install -r requirements-engine.txt
cp <your license file> fluvv.lic
fluvv license report

# Upstream first: bronze, then silver, then gold.
fluvv ingest contracts/bronze/sales/*.yaml contracts/silver/sales/*.yaml contracts/gold/sales/*.yaml
```

Spark needs Java 17 or later. Each table is written as Delta under `data/`,
with its run records next to it. Test a table against its contract:

```python
from fluvv import Contract

run = Contract("contracts/gold/sales/cars.yaml").test()
print(run.result)
```

To publish everything to OpenMetadata, start it (Docker, at least 6 GiB of
memory), then create Fluvv's bot with an admin token from it, and push:

```bash
PIPELINE_SERVICE_CLIENT_ENABLED=false docker compose -f openmetadata/docker-compose-postgres.yml \
  up --detach postgresql elasticsearch execute-migrate-all openmetadata-server

export OPENMETADATA_ADMIN_TOKEN="<an admin token from OpenMetadata>"
fluvv setup-openmetadata --env-file .env
set -a && . ./.env && set +a
fluvv push-openmetadata
```

Then open http://localhost:8585. The docs cover
[connecting](https://fluvv.se/docs/connecting-to-openmetadata) and
[what lands where](https://fluvv.se/docs/what-lands-where).
